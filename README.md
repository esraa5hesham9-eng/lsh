Project 2: Building a Unix Shell (LSH)

Project Overview

Developed a minimal Unix shell called LSH (Little Shell) using C. The project demonstrates how shells read and process user commands, execute external programs, and manage processes using POSIX system calls.

Features

- cd: Change the current working directory.
- help: Display available built-in commands.
- exit: Exit the shell.
- pwd: Display the current working directory.
- echo: Print user-provided text.
- history: Store and display previously entered commands.
- env: Display environment variables.

Technologies Used

- C Programming Language
- Linux
- POSIX System Calls
- C Standard Library

How to Run

Compile the program:

gcc src/main.c -o lsh

Run the shell:

./lsh
